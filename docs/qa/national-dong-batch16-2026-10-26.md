# 전국 행정동 16차 batch — 상동(경기 부천) (2026-10-26)

## 경위
- 처음으로 서울 밖(경기) 후보를 넓혀 조회했다. `school-import.ts --dongs`(저장 없음)로 전국 후보 2,910개 동을 점수화하고, 경기 16개 동(69교)의 학교알리미 2026년 3차 공시·첨부 형식을 읽기 전용으로 조회했다(NOTFOUND 4교). 이 중 부천 상동·오정동, 안양 부림동·귀인동 4개 동 15교를 수집(13~15차와 같은 Node 수집기·manifest·셀 주소 표 덤프, repo 미변경)했다.
- **1개 동(상동)만 진행했다.** 나머지는 근거가 부족하거나 서식을 확정하지 못해 제외했다.
  - 오정동: 덕산중 계획서가 3학년 중심이고 영어·음악이 1학기 계획이며, 덕산고·덕산초는 표 구조가 달라 5과목을 확정할 수 없음.
  - 귀인동: 백영고·민백초·귀인중이 모두 PDF 텍스트층 없음(PDF_HEAVY) → 사용 가능 학교 1곳.
  - 부림동: 평촌경영고(합본 HWP)·부안중(교과별 14개)·부림초의 서식이 서로 달라 이번에 대응을 확정하지 못함(부림중·안양부안초는 PDF_HEAVY). 다음 후보.
  - 역곡1동: 역곡고 PDF_HEAVY, 역곡중·부천역곡초는 서식이 달라 확정 못 함.

## 사용한 값 / 제외한 값
- 사용: 정기시험·수행평가 비율, 논술형 합계(표 합계 검산), 수행평가 과제명·비율·시기, 송내초 6학년 단원별 방법·월.
- 제외·주의
  - **상도중 2학년 역사**: 수행평가 합이 시험 50%와 맞지 않는다(20+20 ≠ 50, 한 과제 30점이 20%) → 비율을 쓰지 않았고 사회 페이지에는 1·3학년 사회와 3학년 역사의 한 과제만 썼다. **상도중 3학년 역사**는 과제 이름 2개에 비율 3개(25/10/15)가 인쇄돼 임진왜란 다시 쓰기(25%)만 썼다.
  - **상도중 2학년 과학**: 세 번째 과제가 10점인데 20%로 인쇄 → 이 과제 비율은 쓰지 않았다.
  - **부천여고 과학탐구실험2** 네 번째 과제명이 표에서 잘려 이름을 쓰지 않았다. **미적분Ⅰ** 수행 네 과제 중 앞 두 과제만 이름을 썼다(나머지 과제명이 불완전). 부천여고 2학년은 일부 교과만 사용했다.
  - **상도중 영어**: 1학기 계획이 아니라 2학기 표만 사용(덕산중은 영어가 1학기 계획이라 오정동 제외).
  - 송내초 영어: 같은 달(9월)에 서술형 세 번이 인쇄돼 있으나 원문 그대로 적었다(총 횟수 문구 없음).
- 난이도·성적·학군·학원 수·후기 등은 쓰지 않았다.
