## 2. 설계 결정

1. **URL은 바꾸지 않는다.** 1,400+ route가 이미 색인/공유 중이고, 계층은 breadcrumb·내부링크로 표현한다.
   학교 페이지 breadcrumb: `홈 > 지역별 과외 > 서울 과외 > 강서구 과외 > 초등학교 > ○○초등학교 과외`.
   "학교급" 단계는 기존 `/region/{시도}/{시군구}/{elementary|middle|high}` 허브로 연결하고, 그 허브에
   해당 학교급 학교 목록 + 학년별(초1~6 등) 링크를 추가했다(정책상 noindex 유지).
2. **논술은 program으로 추가**(`/program/nonsul`). subject로 넣으면 지역×과목·학교×과목·지역×학년×과목
   조합이 수백 개 늘어나 thin page만 증가한다. 코딩·검정고시와 같은 모델이며 지역×논술 23개는 noindex.
3. **공통 학습 정보 레이어 분리** (`src/data/subjectStudyGuide.ts`). 같은 문단이 두 index 페이지에
   동시에 나오지 않도록 필드를 페이지 유형별로 나눴다.
   - 과목 페이지: 학교급별 차이 / 개념·문제풀이 병행법 / 내신 대비
   - 지역×과목 페이지: 성적이 안 오르는 이유와 해결 / 시험 4주 계획 / 1:1이 도움되는 경우
   - 지역 고유 부분(소개, 학년별 안내, 지역 고려사항, 지역 FAQ)은 `regionSubjectContent.ts`에만 둔다.
4. **index 기준은 그대로**: 지역 고유 콘텐츠 entry가 있어야만 지역×과목 index. 공통 가이드만으로는 index 불가.
5. **RSS ≠ sitemap**: RSS는 정보성 글(guide, 학년별, 과목 주제)만. 지역/학교 랜딩은 제외.

## 4. 확대 전 확인이 필요한 리스크

- **지역×과목 고유성의 한계**: 지역 고유 사실로 쓸 수 있는 것은 등록 학교·행정구역 정보뿐이다.
  학교별 시험 범위·교재·학사일정 같은 진짜 지역 정보는 학교알리미 등 공개자료 확인이 필요해
  이번에 만들지 않았다. 확인된 데이터 없이 115개 조합을 채우면 "지역명만 바꾼" 패턴이 된다.
- **14개 시·도 페이지**: 직전 감사(index-seo-audit-2026-09-30)에서 지역명 가림 시 서로 100% 동일로
  판정됐고 현재도 index 상태. 하위 지역/학교 데이터가 없는 한 콘텐츠로 해결하기 어렵다 → 사용자 결정 필요.
- **시·도 단위 과목 페이지(예: 충남수학과외)**: route 자체가 없다. 만들면 17×5=85개 신규. 해당 지역
  학교/하위지역 데이터 없이 만들면 위와 같은 중복 문제 → 하위 데이터 확보 후 진행 권장.
- **카테고리별 OG 썸네일**: 실제 이미지 파일이 없고, `next/og`로 생성하려면 한글 폰트 파일이
  필요하다(현재 저장소에 없음). 가짜 URL/깨진 이미지를 만들지 않기 위해 보류.
