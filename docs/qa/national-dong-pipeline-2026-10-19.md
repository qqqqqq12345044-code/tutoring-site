# 전국 행정동·학교 데이터 구조 (2026-10-19)

## 공식 행정동 표 — `data/official/admin-dongs.json`
- 출처: 행정안전부 "행정기관(행정동) 및 관할구역(법정동) 변경내역(2026.10.12. 시행)" 첨부 `jscode20261012.zip`
  (KIKcd_H = 행정동코드·시도·시군구·읍면동, KIKmix = 행정동↔법정동/리). 말소코드 미포함본.
- 생성: `npx tsx scripts/official/admin-dongs.ts --src <압축 푼 폴더> --source-url <게시글 URL> [--write]`
  (기본 dry run, 이전 JSON과 +/− 행정동 diff 출력, 헤더 바이트 위치가 바뀌면 중단).
- 규모: **시도 16 / 시군구 241 + 일반구 39 / 읍면동 3,629 (동 2,157·읍 238·면 1,170)**, 법정동·리 20,299 중
  19,546개(96.3%)는 행정동 1곳에만 속하고 753개는 여러 행정동에 걸침.
- 앱 번들에 넣지 않음(scripts·validator만 읽음). 페이지 대상 행정동은 계속 `src/data/dongs.ts`.

### 공식 표와 사이트 지역 구조의 차이 (자동 대응하지 않음)
- **전남광주통합특별시(1200000000)**: 공식 표는 광주광역시·전라남도를 하나의 시도로 묶음. 사이트 `regions.ts`는
  광주(5개 구)·전남(22개 시군)을 따로 둠 → 27개 지역은 공식 시군구와 대응하지 않음(구조 결정 필요, 보류).
- 인천 개편: 제물포구·영종구·서해구·검단구는 사이트 slug(jemulpo 등)와 대응됨. 중구영종출장소 등 출장소 행은 페이지 대상 아님.
- 세종특별자치시: 시군구명이 비어 있는 단층 구조. 사이트는 도(province) 노드만 있음 → 행정동 페이지 대상 아님(보류).

## 학교 → 행정동 — `data/official/school-dongs.json`
- 생성: `npx tsx scripts/official/school-dongs.ts [--verbose] [--write]`, 전국 학교 수: `--national-counts`.
- 방법: NEIS 학교기본정보(학교코드, 없으면 교육청 안 정확한 학교명 1건) → 상세주소 괄호 안의 법정동 →
  KIKmix에서 그 법정동이 시군구 안 행정동 1곳에만 속하면 확정(`legal-dong-unique`). 여러 행정동에 걸치면 **pending**.
  `JUSO_CONFM_KEY`(주소정보누리집 도로명주소 검색 API 승인키, 환경변수)가 있으면 API의 행정동명으로 확정(`juso-api`).
  의정부 70개교는 기존 주소정보누리집 확인값을 공식 후보와 교차검증(`site-verified`); 의정부광동고는 문서화된 예외.
- NEIS 요청: 키 없이 학교 단위 조회, `.cache/official/neis/`에 캐시(gitignore), 요청 간격 400ms. `NEIS_API_KEY`가 있으면 사용.
- 결과(등록 190개교): **확정 87 (의정부 70 + 공식 표 1:1 17) / pending 103** (법정동이 여러 행정동에 걸침 99,
  NEIS 상세주소에 법정동 없음 4). pending은 승인키 없이는 풀지 않음(추측 금지).
- 전국 학교 수(NEIS 학교기본정보, 학교급 필터 head 총계): **초·중·고 12,091** (서울 1,320 · 경기 2,587 · 인천 556 …).
  키 없는 NEIS는 목록을 5건까지만 주므로 전국 학교 목록 자체는 `NEIS_API_KEY` 없이는 만들지 않음.

## route 정책 (2026-10-19)
- 행정동 허브: `dongs.ts`에 있는 행정동만(= 공식 표 검증 + 확정된 등록 학교가 있는 동을 사람이 batch로 추가).
- 행정동×과목: **작성된 평가계획 항목이 있을 때만 route 생성** (`hasDongSubjectRoute`). 없으면 404, 링크·sitemap·inventory에서도 제외.
- 색인: 허브·과목 모두 품질 게이트 GREEN만(`checkDongIndexedGreen`), RED는 `qualityNoindex.ts`.
- slug: `-dong` / `-eup` / `-myeon`. 통·반 수는 시 자체 표가 있을 때만.
- 이론상 최대: 3,629 허브 + 3,629 × 5 = 18,145 과목 route. 실제 생성은 위 조건을 통과한 것만.
