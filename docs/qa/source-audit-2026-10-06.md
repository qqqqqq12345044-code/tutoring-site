# 출처 감사 — GREEN 11개 페이지 (2026-10-06)

STEP 8에서 위키백과로 확인했던 6개 페이지를 공식 자료로 교체하고, 추가로 승격한 5개 페이지(강서구 수학, 미추홀구 영어, 수원·서초·양천 중등)의
출처를 같은 기준으로 정리했다. 각 URL은 작성 시점에 **실제로 열어서** 해당 문장을 뒷받침하는 것을 확인한 것만 넣었다.

## 사용한 공식 자료

| 자료 | 용도 | 확인 방법 |
|---|---|---|
| 교육부 NEIS 교육정보 개방 포털 — 학교기본정보(`open.neis.go.kr/hub/schoolInfo`) | 학교 소재지(구·동)·공립/사립·남녀공학 구분·설립일·특목고 유형 | 시·도교육청 코드 + 학교 표준코드로 지정한 URL이 인증키 없이 **정확히 1건**을 반환하는지 33개 전부 확인 |
| 성남·용인·안양·고양·수원·부천 시청 연혁/행정구역 페이지 | 구 설치 연혁, 동의 구 소속 | 페이지 원문에서 날짜·문구 대조 |
| 인천광역시 행정체제 개편 개요·보도자료 | 2026-07-01 개편 내용, 미추홀구 등 유지 구 | 원문 인용 확인 |
| 마포고등학교 학교연혁 | 1985.02 강서구 등촌동 신교사 이전 | 학교 공식 홈페이지 원문 확인 |

NEIS URL은 JSON을 반환하는 API 기록이다(사람이 읽기에 최적은 아님). 학교 코드 지정 이유: 이름 검색은 부분 일치라 `인천고등학교`가
5건(동인천고·서인천고 등 포함)으로 섞였다. 새 학교를 쓰려면 `src/data/sources.ts`의 `NEIS_SCHOOLS`에 코드를 먼저 추가한다.

## 공식 자료에서 확인되지 않은 항목 (쓰지 않음)

- 검색 요약이 "죽전중학교는 동천동"이라 했으나 NEIS는 **수지구 죽전동**(검색 요약 오류).
- 안양중학교 개교 시점은 NEIS에서 설립일 1947-07-14, 개교기념일 1948-03-15로 달라 연도를 한 개로 못 박지 않고 "1940년대 설립"으로 표기.
- 성남시 "현재 구 구성" 전용 공식 페이지는 열리지 않아(404), 연혁 페이지의 구청 설치 기록으로 3개 구를 서술.
- 수원시 행정구역 소개 페이지는 구 설치일을 담고 있지 않아, 영통구청 연혁 페이지(1988·1993·2003 구 설치)를 출처로 사용.
- 인천 개편 보도자료(2024-01-09 게시)는 예정 시점 문구이며, 시행(2026-07-01)은 인천시 개편 개요 페이지로 확인.

## 한계

- NEIS 응답은 조회 시점의 값이다. 학교 주소·유형이 바뀌면 달라질 수 있어 **분기마다 재조회**를 권장한다.
- 사실(소재지·설립)은 확인했지만, 학교별 시험범위·성적·학군은 여전히 쓰지 않았다.
- 출처 URL이 살아 있는지는 검증 스크립트가 형식(https·중복·라벨)만 검사한다. 링크 생존 점검은 별도 수동 확인이 필요하다.
