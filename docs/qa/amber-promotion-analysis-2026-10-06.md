## 2. AMBER 61개 부족 요소 분류

한 페이지가 여러 항목에 해당하므로 합계는 61을 넘는다. (게이트의 구조 조건 — 해당 학교급 등록 학교 유무 — 은 전부 통과해 "지역 정보 부족 / 학교 데이터 0"인 AMBER는 없다.)

| 부족 요소 | 지역×과목 (2) | 지역×학년×과목 (9) | 학교×과목 (50) |
|---|---|---|---|
| 출처(sources) 없음 | 2 | 9 | 50 |
| 실질 note 부족 (<2) | 1 | 8 | 50 |
| 이름 마스킹 유사도 >30% | 0 | 9 (32~60%) | 50 (44~60%) |
| 공통 가이드(playbook) 없음 | 0 | 1 (`anyang/high/english`) | 0 |

해석:
- **출처 없음은 전수 공통**이다. 사실을 쓰고도 출처를 적지 않아 GREEN 후보가 0이었다.
- **학교×과목 50개**는 구조적으로 막혀 있다. 학교별 고유 사실이 없어(학교명 외 확인된 정보가 없음) note가 1개, 서로 44~60% 유사하다. 학교알리미/NEIS 같은 학교별 공개자료 없이는 올릴 수 없다 → **이번 승격 후보에서 제외**.
- **지역×학년×과목 9개와 지역×과목 2개**는 사실 조사로 올릴 수 있다.

## 3. STEP 8에서 얻은 근거 (후보 예상치에 반영)

1. **사실이 있으면 GREEN이 나온다.** 1차 문서로 확인한 행정구 연혁 + 등록 학교의 실제 소재지만으로 6/6 GREEN(유사도 17~21%).
2. **같은 문장 틀은 바로 30%를 넘긴다.** 첫 초안은 "○○는 △△구 □□동에 N년 문을 연 공립 중학교입니다 / 아직 등록되어 있지 않습니다"를 반복했고 3건이 30~31%(AMBER)였다. 페이지마다 *다른 정보*(구 편성 방식, 구청 승격 과정, 교명≠소재 동 등)를 담도록 다시 써서 통과했다. 지역명 치환 템플릿은 의도대로 걸러진다.
3. **도시·학교급 하나당 확보된 사실 풀은 사실상 1페이지분이다.** 성남·부천·고양·안양·용인·송파의 사실은 STEP 8 페이지가 이미 사용했다. 같은 도시·학교급의 다른 과목(예: 성남 중등 수학)을 올리려면 겹치지 않는 *새* 사실이 필요하고, 같은 사실을 다시 쓰면 둘 다 유사도에서 탈락한다.
4. 검색 요약만 믿으면 틀린다. 용인 죽전중학교 소재가 검색 요약에선 "동천동"이었으나 1차 문서는 "수지구 죽전동"이었다. 모든 후보는 1차 문서(위키백과 학교·시 문서, 공식 보도) 직접 확인을 전제로 한다.
